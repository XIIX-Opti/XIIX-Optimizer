# Compatibility

XIIX-Optimizer is designed to improve Windows performance through system optimization.

## Supported Operating Systems

- Windows 10
- Windows 11

## Requirements

- A supported Windows installation.
- Administrator privileges for operations that require them.
- A system restore point or backup before applying system changes.

## Important Notes

Compatibility may vary depending on your Windows version, hardware, and system configuration.

More details will be added as testing progresses.
